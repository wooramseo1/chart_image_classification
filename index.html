    Strategy Guide

    패턴별 대응 전략

    모델이 판별하는 두 가지 패턴과, 에이전트가 적용하는 기본 전략 규칙입니다.

    Class 01

    Trend Line · 추세선

    저점(또는 고점)을 연결한 직선 위에서 가격이 일정한 방향성을 유지하는 구간입니다.

    • 상승 추세 — 추세선 지지 확인 후 눌림목 분할 매수
    • 하락 추세 — 반등 시 저항 확인 후 비중 축소 / 관망
    • 손절 — 종가 기준 추세선 명확한 이탈
    • 핵심 — 추세 추종(Trend Following)
    Class 02

    Triangle Pattern · 삼각수렴

    고점은 낮아지고 저점은 높아지며 변동폭이 수렴하는 구간으로, 큰 방향성 이탈을 앞둔 경우가 많습니다.

    • 대기 — 수렴 구간 내부에서는 신규 진입 자제
    • 진입 — 거래량 동반 상단/하단 돌파 방향으로
    • 목표 — 삼각형 최대 폭만큼 돌파 지점에서 투영
    • 핵심 — 돌파 매매(Breakout)
    조건에이전트 판단액션
    Trend Line ≥ 기준 · 상승추세 지속 가능성 높음추세 추종 매수
    Trend Line ≥ 기준 · 하락하락 추세 지속비중 축소
    Triangle ≥ 기준변동성 수렴 → 돌파 임박돌파 대기
    최고 확률 < 기준패턴 신호 불명확관망
    How it works

    Chart Strategy Agent 작동 원리

    4단계 파이프라인이 모두 사용자 브라우저 안에서 실행됩니다.

    1. 01

      이미지 입력

      업로드한 차트 이미지를 캔버스로 로드합니다.

    2. 02

      전처리

      모델 입력 크기(224×224)에 맞게 중앙 크롭 및 정규화합니다.

    3. 03

      AI 추론

      MobileNet 기반 전이학습 모델이 클래스별 확률을 계산합니다.

    4. 04

      전략 결정

      확률·신뢰도 기준·추세 방향·투자 성향을 규칙 엔진에 적용합니다.
